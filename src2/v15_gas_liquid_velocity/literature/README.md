# Literature evidence

See [the literature review](../findings/literature_review.md) for equations, pages, limitations and conclusions.

- extracts: local PDF text, source-retrieval evidence and a pinned copy of the secondary fluids implementation. The original Xu–Fang 2014 full text was not obtained.
- pages: rendered PDF equation/table evidence, including the high-resolution printed exponent −2.
- source_numeric_checks.py and source_numeric_checks.json: reproducible conservation/table-consistency calculations, not measurements of model accuracy.

The main PDFs remain in the repository assets directory and are linked from the review. The −2 form in de Oliveira 2021 and −0.2 form in the pinned secondary implementation remain separate named experiments. Published accuracy percentages are not applied to this dataset.
