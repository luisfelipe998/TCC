ARTICLE                  INFO                                 ABSTRACT

Keywords:                                                     Recognizing flow patterns is essential for understanding two-phase flow phenomena, applicable to various
Two-phase flow patterns                                       fields such as liquid/gas mixtures, refrigeration, convective boiling, and more. The application of visual image
Flow pattern classification                                   processing provides a means to automate the interpretation of two-phase flow patterns. This article aims to
Image processing
                                                              enhance the accuracy of two-phase flow patterns classification during convective boiling of isobutane in a
Machine learning
                                                              horizontal tube with 1 mm diameter. For this, the classification of gas/liquid two-phase flow patterns used
                                                              image processing for texture features extraction applied to a kNN model. Five different flow patterns were
                                                              identified using images obtained from a high-speed camera, including isolated bubble, plug, slug, churn and
                                                              wavy-annular flow. The method achieved promising results with the best F1-Score of 97 % for bubbles and
                                                              the worst of 81 % for plug and slug patterns.

                                                                                             The kNN method does not have in fact a training step. The method
                                                                                         computes the distance of a new point to all points in the train dataset.
                                                                                         Then it assigns to the new point the label of the k nearest points from
                                                                                         the train dataset. Therefore, to expand the model with new image
                                                                                         features the idea is simply add the new ones to the train dataset.
                                                                                         On other words, in this particular case it is simple to expand and
                                                                                         increase the generalization, i.e. adding features from images of other
                                                                                         experimental facilities. The limitation of this method is on the dataset.
                                                                                         Thus, to make the method more generalized the dataset should be more
                                                                                         general.
                                                                                             An well established method to deal with the unbalanced dataset
                                                                                         is the usage of data augmentation in classes with fewer images. This
                                                                                         leads to a discussion over these solutions in the problem of propagate
                                                                                         bad assigned information on the machine learning model since the new
                                                                                         data is based on existent ones. On other words, a bad annotation in the
                                                                                         original dataset could have this error amplified and propagate over the
                                                                                         kNN model. Another point is that data augmentation on the images may
                                                                                         have low influence on kNN performance, as an example, the rotation
                                                                                         in image results in the same texture features values as the original
