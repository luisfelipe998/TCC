# Figuras de apoio

`panoramas/` contém quatro exemplos experimentais. `metodologia/` contém o fluxograma, o exemplo sintético dos perfis wavelet, o recorte real com sua máscara e o exemplo sintético das medidas ópticas. Os arquivos de origem identificam quais exemplos são reais e quais são sintéticos. Todos os geradores estão em `../scripts/`.

Para reproduzir toda a análise, use `python3 -B executar.py --workers 2` a partir da raiz da v18. Consulte `../METODOLOGIA.md` e `../README.md`.
