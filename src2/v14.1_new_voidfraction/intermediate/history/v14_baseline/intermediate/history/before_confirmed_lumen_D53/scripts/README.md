# Scripts and reproduction

[Back to v14](../README.md)

Run the main pipeline from the repository root:

```sh
python3 -B src2/v14_new_voidfraction/scripts/run_all.py
# Also regenerate earlier raw-frame alternatives:
python3 -B src2/v14_new_voidfraction/scripts/run_all.py --include-exploratory
# Show the dependency order without running:
python3 -B src2/v14_new_voidfraction/scripts/run_all.py --list
# Verify current scope, retained measurements and navigation:
python3 -B src2/v14_new_voidfraction/scripts/verify_layout.py
```

The runner uses the active Python interpreter, absolute script paths and a working directory derived from its own location. It stops at a failed stage and writes logs to [intermediate/logs/](../intermediate/logs).

From another directory, use the same interpreter that generated this index (Python environment selection can depend on the working directory):

## Ordered main stages

| Order | Script | Purpose |
|---|---|---|
| 1 | [panorama_void_alternatives.py](panorama_void_alternatives.py) | Infer liquid references and reconstruct conditional visible gas area. |
| 2 | [phase_mask_flip_analysis.py](phase_mask_flip_analysis.py) | Save gas masks and calculate spatial gas-silhouette flips. |
| 3 | [raw_flip_analysis.py](raw_flip_analysis.py) | Reproduce legacy optical flips and supplemental native-frame checks. |
| 4 | [spatial_flip_sensitivity.py](spatial_flip_sensitivity.py) | Perturb spatial optical thresholds and radial crops. |
| 5 | [inventory_and_legacy_audit.py](inventory_and_legacy_audit.py) | Record input hashes and independently audit legacy values. |
| 6 | [pattern_identification.py](pattern_identification.py) | Compare fixed morphology classifiers and create the contact sheet. |
| 7 | [silhouette_pattern_identification.py](silhouette_pattern_identification.py) | Compare silhouette classifiers with training-fold references. |
| 8 | [adversarial_review.py](adversarial_review.py) | Challenge masks with phase anchors, reference choices and crops. |
| 9 | [deep_method_checks.py](deep_method_checks.py) | Test corrected morphology and equations; quantify changes against the pre-review snapshot. |
| 10 | [final_verification.py](final_verification.py) | Independently verify saved arithmetic, input hashes and classifier scores. |
| 11 | [summary_figures.py](summary_figures.py) | Plot void versus spatial flip-rate and crop sensitivity from saved results. |
| 12 | [write_summary.py](write_summary.py) | Generate the executive summary and folder navigation. |
| 13 | [post_regeneration_adversarial.py](post_regeneration_adversarial.py) | Independently challenge the completed analysis, plots and findings. |
| 14 | [verify_layout.py](verify_layout.py) | Verify current exclusions, retained measurements and report navigation. |

The optional [image_void_alternatives.py](image_void_alternatives.py) stage writes the earlier alternatives under intermediate/exploratory and runs before final verification.

## Paths and dependencies

[v14_selection.py](v14_selection.py) applies the approved acquisition and pattern exclusions before computation. [v14_paths.py](v14_paths.py) resolves the v14 root, src2/data_processed inputs, caches and report links. [artifact_layout.json](artifact_layout.json) maps artifact names to destination folders. Register a new output there before using artifact_path(). [v14_navigation.py](v14_navigation.py) defines the folder indexes regenerated by write_summary.py.

[verify_layout.py](verify_layout.py) checks current exclusions and compares retained per-run measurements and masks against the archived previous analysis and checks local report links. Mask changes are checked against the independent method-correction ledger; groups and classifiers are recomputed.

Dependencies: NumPy, Pillow, SciPy and Matplotlib. Legacy comparisons additionally read src2/v11.3 code. Literature extracts and historical review notes are preserved documents rather than pipeline-generated outputs. Use -B for individual runs as well to avoid loose bytecode caches.
